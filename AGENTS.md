# AGENTS.md

Cloudflare Workers app that serves a vanilla TypeScript browser speed test (Vite build, no framework, Japanese UI copy).

## Commands

- `npm run dev` – Vite dev server. UI only: `/api/*` does not exist here (no vite proxy configured), so packet-loss measurement silently degrades.
- `npm run preview` – build + `wrangler dev`. Use this to exercise the full app including `/api`.
- `npm run deploy` – build + `wrangler deploy`.
- `npm test` / `npx vitest run score.test.ts -t "<name>"` – vitest with defaults; `src/score.test.ts` is the only suite.
- Lint/format via Biome (`npm run lint`, `npm run format`, `npm run format:check`). Single quotes, spaces.
- CI (.github/workflows/ci.yml) runs two parallel jobs on main pushes/PRs: `lint` + `format:check`, and `test` + `build`. `build` = typecheck both tsconfigs, then `vite build`.

## Architecture

- `src/main.ts` – client entry (loaded by root `index.html`): DOM UI, canvas chart, score display.
- `src/engine/engine.worker.ts` – Web Worker running the measurement phases (latency → loss → download → upload) against `speed.cloudflare.com` (or `h3.speed.cloudflare.com` when host=h3). Packet loss runs on the main thread in `src/engine/packet-loss.ts` (RTCPeerConnection is not available inside workers); the engine worker delegates to it via the `measure-loss` / `loss-result` protocol messages, with TURN credentials still fetched from `POST /api/turn-credentials`.
- `src/engine/protocol.ts` – shared message contract between main thread and engine worker.
- `src/score.ts` – pure scoring math (grades S–E).
- `src/worker.ts` – Worker entry (per wrangler.jsonc): serves static assets from `dist/` via the ASSETS binding plus the single API endpoint above (origin check + in-memory per-IP rate limiting).

## Gotchas

- Two separate tsconfigs: root covers all of `src/` **except** `src/worker.ts`; `tsconfig.worker.json` covers **only** `src/worker.ts` (+ its imports, workers types). Files not reachable from either entry are never typechecked.
- `verbatimModuleSyntax` is on in both configs: type-only imports must use `import type` or the build fails.
- TURN secrets `TURN_KEY_ID` and `TURN_TOKEN` are required for packet loss: set via `wrangler secret put` (prod) or `.dev.vars` (local wrangler dev). Without them `/api/turn-credentials` returns 503 and loss shows `--`.
- `dist/` is generated by `vite build` and gitignored; don't edit it.
